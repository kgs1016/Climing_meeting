# 보관 — 로테이션 & 공통점 카드

2026-08 에 **제거**한 기능의 구현체입니다. 빌드에 포함되지 않습니다.
되살릴 일이 생기면 여기서 가져다 쓰면 됩니다.

## 왜 뺐나

시간표가 자유도를 제한했습니다.

- "지금부터 30분간 이 사람과" 는 학원 시간표처럼 느껴집니다.
- **1:1 을 열면서 로테이션의 의미가 사라졌고**, 2:2 도 2라운드뿐이라
  구조 대비 얻는 게 적었습니다.
- 대신 **모임 확정 후 참가자 프로필을 자유롭게 열람**하고,
  **영상은 각자 자유롭게 인증**하는 방식으로 바꿨습니다.

## 무엇이 들어 있나

| 파일 | 내용 |
|---|---|
| `session_room.sql` | 라운드 페어링을 계산해 내려주던 RPC. 남 i ↔ 여 (i+r-1)%n |
| `room-page.tsx` | 라운드별 카드·미션 UI (모임 진행 화면) |
| `matchCard.ts` | 두 프로필을 비교해 공통점 카드를 만드는 로직 (Tier1/2/3 + 대화 씨앗) |

## 되살릴 때 주의

- `missions` 테이블은 `(session_id, round, user_id)` 가 기본키였고
  `partner_id` 가 NOT NULL 이었습니다. 현재 구조와 다릅니다.
- 로테이션 공식은 검증돼 있습니다 — `n:n → n라운드`, 모든 이성과 정확히 한 번씩.
  `n=1,2,3` 전수 확인 완료.
- `matchCard.ts` 는 취향 설문(15문항)이 붙으면 Tier2 가 두꺼워지도록
  설계돼 있습니다. 지금은 프로필 필드만 재료로 씁니다.
